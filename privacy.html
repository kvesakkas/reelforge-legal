Privacy Policy

Last updated: 26 November 2026

ReelForge is run by Kyriacos Sakkas, Nicosia, Cyprus. Today he is its only user and the owner of every connected account, so the only personal data it handles is his own. If ReelForge opens to more users, the same rules below apply to each of them, and this policy will be updated first.

What data it stores

  • Access tokens from each connected platform (TikTok, YouTube, Instagram, Facebook, Threads). They let the app upload videos to the connected accounts.
  • Basic profile details of each connected account: display name, @username, profile picture link, and the platform's account id. These are only used to show which account is connected.
  • Post records: which video went to which account, when, and the link or status the platform returned.

ReelForge does not collect data about viewers, followers or anyone else. It does not use cookies for tracking, analytics or ads. The only cookie is the login session for its own dashboard.

This website

This website is static and hosted on GitHub Pages. It sets no cookies and has no analytics or forms. GitHub may log visitors' IP addresses for security, as described in GitHub's own privacy statement.

How it is stored

Everything is kept on ReelForge's own server, in a private network (Tailscale) that only the owner's devices can reach. Tokens and app secrets are encrypted with AES-256-GCM before they are saved.

How it is used

Only to upload approved videos to the connected accounts, and to check whether an upload worked. On TikTok the app uses user.info.basic (and user.info.profile for the @username) to show the connected account, and video.upload to send a video to the TikTok inbox as a draft. If Direct Post is turned on later, it uses video.publish to post to the connected profile with the privacy and interaction settings the owner chooses.

Sharing

No data is sold, rented or shared with anyone. It is only sent to the platform the video is being uploaded to.

Deletion

When an account is disconnected in ReelForge ("Disconnect"), its tokens and profile details are deleted at once. Access can also be removed at any time in the platform's own settings (on TikTok: Settings and privacy → Security → Manage app permissions). Access tokens that are not refreshed run out by themselves (TikTok: 24 hours, refresh token 365 days). Deletion can also be requested by e-mail.

Children

ReelForge is not meant for and does not collect data from children.

Changes

This policy may be updated. The date at the top shows the latest version.
